# TabungPin user guide

1. Open the public app and review the weekly round-up total.
2. Inspect the transactions included in the proposed batch.
3. Connect Freighter and confirm Stellar Mainnet.
4. Create a uniquely numbered batch.
5. Deposit a small XLM amount into that batch.
6. Approve the batch after reviewing its total.
7. Save each successful transaction link.

The demo data is resettable and is not ledger evidence.
