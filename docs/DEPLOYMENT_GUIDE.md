# Deployment guide

1. Run web and contract tests.
2. Validate the deployment manifest.
3. Build the Next.js application.
4. Confirm Mainnet RPC and Horizon configuration.
5. Deploy to Vercel and verify public access.
6. Perform a low-value batch action with Freighter.
7. Record confirmed transaction evidence.

Any contract replacement needs a new WASM hash and explicit manifest update.
